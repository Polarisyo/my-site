## 项目介绍

这是一个专注于写作体验的 Markdown 笔记工具，核心特性包括：

- **实时预览**：左右分屏，所见即所得
- **本地优先**：数据存储在浏览器中，保护隐私
- **快捷键支持**：流畅的键盘操作体验

## 技术实现

使用 React + TypeScript 构建，通过 Vite 实现快速的开发体验。

## 亮点

- 支持数学公式和代码高亮
- 可导出为 PDF 和 HTML
- 响应式设计，移动端友好
